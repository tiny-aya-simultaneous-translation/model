# v0.3 Evals Program — S2ST evaluation harness (TR↔HI)

**Date:** 2026-07-15 · **Status:** IMPLEMENTED same day (all tiers; see
addendum at bottom).

**2026-07-20 update:** the long-horizon run is COMPLETE incl. anneal
(`xzcb60bl` → best 2.8199 @ step 76,000); repo public with the full ~89-ckpt
suite. The GPU release eval has since **run** — results in
`docs/v0.3-eval-report.md`; ops + checkpoint routes in `docs/evals-runbook.md`
("Post-run state").

## Why

Model quality today is measured only by proxies: val CE/ppl, teacher-forced
token accuracy, and TF-text BLEU/chrF against tokenizer-decoded interleaved
text. There is **no end-task metric** — nothing measures whether the generated
audio *says the right thing, intelligibly*. Both
`scripts/average_checkpoints.py` and `scripts/publish_checkpoint_suite.py`
already reference a missing `scripts/eval_release.py`; `src/evaluation/` is an
empty stub. This program fills both, reusing the org's prior eval art and
2024–2026 S2ST evaluation practice (Exa deep-research pass, 2026-07-15).

## Decisions (locked 2026-07-15)

- **Compute:** heavy tiers run on a **rented GPU** (H100/A100, hindi-tts-probe
  pattern) — but **no GPU instance until the long-horizon run completes**.
  Until then everything is CPU/stub-verified.
- **Scope:** all tiers (1, 2, 3 + latency) get implemented.
- **Judges:** local open-source stack produces the reported numbers; Gemini is
  used as ASR referee cross-check + GEMBA-style adequacy judge
  (`GEMINI_API_KEY` via env, never printed).

## Facts the design rests on (verified 2026-07-15)

- Corpus `.pt` files carry **gold `source_text`/`target_text` strings**
  (tr-hi-mimi-encoded dataset card). References are MT-synthetic — every
  report must disclose this. Corpus QC topline: GT audio passed round-trip
  faster-whisper large-v3 at WER ≤ 0.20 (86% pass) → always report the
  **GT-audio topline** next to any ASR-based metric.
- Org ASR-judge benchmark (`hindi-tts-probe/report.md`, N=100):
  **`vasista22/whisper-hindi-large-v2` WER 20.11%** vs whisper-large-v3
  29.43% on synthetic Hindi → Hindi judge = vasista22 (needs the documented
  `forced_decoder_ids` workaround); Turkish judge = whisper-large-v3
  (`language="tr"`). Known scorer bugs to fix in our normalizer:
  candrabindu/anusvara variants, Devanagari-vs-ASCII digits.
- **SONAR speech encoders exist for `hin` and `tur`**; BLASER-2.0 is
  modality-agnostic → QE (source speech + generated speech) and Ref (+ gold
  target **text**) both work. CC-BY-NC-4.0 (eval-only use — fine, noted).
- `tiny-aya-translate/fleurs-tr-hi-mimi-encoded` is already in this repo's
  `.pt`+alignments format (packed tars + splits) → ready-made
  **domain-shift test set**. `lahaja-eval` / `cv-tr-eval` are judge-calibration
  sets only (document the judges' error floor; not model metrics).
- Research verdicts: **chrF++ primary, BLEU secondary** for tr/hi (BLEU noisy
  below ~5); **greedy decoding** for cross-checkpoint comparability; paired
  bootstrap CIs (sacrebleu); MOS predictors are biased on codec speech →
  report **Δ(generated − GT)**, not absolutes; CometKiwi =
  `Unbabel/wmt22-cometkiwi-da` (gated HF repo — accept license once).
- Reusable org code: `sound-quality-check/scoring/{dnsmos,text_metrics,
  gemini_transcribe}.py` (speechmos DNSMOS; jiwer; Gemini referee with
  retries — its Turkish-hardcoded prompt gains a `language` param),
  `codec-finetuning/eval` TTFAT timing methodology + bootstrap CIs.
- Reusable local code: `eval_checkpoint.load_model_and_data()` (canonical
  GCS-aware checkpoint loader), `generate_autoregressive` (gate-validated AR
  loop), `eval_translation_proxy.py` W&B-backfill pattern (`eval/*` keyed on
  `global_step`), `_codebook_entropy_stats` in the trainer.

## Deliverables

### 1. `src/evaluation/` package (all heavy imports lazy)

| module | contents |
|---|---|
| `normalize.py` | `normalize_hi()`: NFC, candrabindu↔anusvara unification, Devanagari↔ASCII digit harmonization, punct strip, whitespace collapse (port of hindi-tts-probe `norm()` + the two flagged bugs). `normalize_tr()`: Turkish-aware casefold (İ/i dotted-I), punct strip. Version-stamped (`NORM_VERSION`). |
| `subset.py` | Frozen eval subsets: seeded (1337) length-stratified draw per direction from a split jsonl → `eval/subsets/<name>.jsonl` with embedded sha256 self-digest; loader refuses on mismatch (identical subsets across checkpoints, guaranteed). |
| `stats.py` | `_codebook_entropy_stats` factored out of the trainer (trainer imports from here; equivalence pinned by the existing unit test) + generation-time codebook histogram collection. |
| `asr_judge.py` | Pluggable judges: `hi` → vasista22 (transformers path with `forced_decoder_ids` fix; faster-whisper CUDA path where possible), `tr` → whisper-large-v3, `gemini` referee (org port + `language` param, ThreadPool + retries). Uniform `transcribe(paths, lang) -> list[str]`. |
| `text_metrics.py` | sacrebleu corpus BLEU + **chrF++ (primary)**, jiwer WER/CER on normalized text, paired-bootstrap CIs + A/B significance (`paired_bs`). Toplines = same judge on GT target audio. |
| `mos.py` | DNSMOS (speechmos) + Distill-MOS (`distillmos`), 16 kHz resample, scored on generated AND GT wavs; report Δ(gen−GT). |
| `semantic.py` | BLASER-2.0 via `sonar-space`: QE(src-speech, gen-speech) + Ref(+gold target-text embedding); CometKiwi QE (transcript vs source_text) + COMET-ref (vs gold target_text) via `unbabel-comet`. |
| `llm_judge.py` | GEMBA-style Gemini adequacy 1–5: source_text + judge-ASR transcript of generated audio; temperature 0, rubric, ~100 stratified samples, repeat-pass self-consistency reported. |
| `latency.py` | RTF + time-to-first-audible-frame of the AR loop (perf_counter, warmup excluded — codec-finetuning TTFAT methodology). |
| `report.py` | Versioned `results.json` (ckpt id/revision, subset digest, judge ids, NORM_VERSION, metric lib versions, decoding params, seed, timings) + W&B backfill at the checkpoint's global_step + optional HF push to the release repo under `eval/`. |

### 2. `scripts/eval_release.py` (the missing orchestrator)

Stages `generate → asr → text → mos → semantic → judge → latency → report`;
`--stages` selectable and **resumable** (per-stage manifest jsonl,
sound-quality-check pattern); `--checkpoint` accepts local dir, `gs://`, or HF
`--hub_revision step-N` (weights-only hub bundles suffice — verify
peft_adapter presence during the live check); `--subset`, `--device cuda|cpu`,
`--ar_temp 0` (greedy default; one sampled config only for listening samples).
Generation reuses `load_model_and_data` + `generate_autoregressive`.

### 3. Frozen eval sets (committed to the repo)

- `eval/subsets/v03-val-500.jsonl` — 250/direction from `val.jsonl` (in-domain).
- `eval/subsets/v03-fleurs-200.jsonl` — from fleurs-tr-hi-mimi-encoded val
  split (domain shift). **Before freezing: overlap audit** vs the training
  corpus on normalized text (leakage check; result recorded in the subset
  header).

### 4. Tier 1 upgrade of `scripts/eval_translation_proxy.py` (CPU sweeps)

Gold refs from `.pt` `target_text` (fallback: tokenizer-decoded, labeled as
such), normalization applied, chrF++/BLEU + CIs, `--subset` support, optional
free-running text decode (the current AR loop teacher-forces text — a flag
measures AR text quality). W&B backfill contract unchanged.

### 5. Metric bundle per tier

- **Tier 1 (CPU, any checkpoint):** TF text chrF++/BLEU vs gold refs + CIs;
  existing TF token accuracies; codebook entropy/active-frac.
- **Tier 2 (GPU, milestone checkpoints):** AR generate (greedy, frozen
  subset) → ASR-chrF++/BLEU/WER per direction with GT-audio topline; DNSMOS +
  Distill-MOS (Δ vs GT); generation-time codebook stats; RTF/TTFA.
- **Tier 3 (GPU, release candidates):** BLASER-2.0 QE+Ref; CometKiwi +
  COMET-ref on transcripts; Gemini GEMBA adequacy + Gemini-vs-whisper judge
  agreement; the FLEURS domain-shift subset through ALL stages; paired
  bootstrap A/B for best-vs-LAWA-vs-final.

### 6. Deps, tests, CI, docs

- `pyproject.toml` optional group `eval`: faster-whisper, jiwer, speechmos,
  onnxruntime, distillmos, sonar-space (+fairseq2), unbabel-comet,
  google-genai. Core deps untouched; ALL imports lazy → torch-free CI stays
  green (`importorskip` in tests).
- Tests: normalizer goldens (candrabindu, digits, Turkish İ/i), subset
  determinism + digest refusal, text_metrics on toy fixtures, stats
  equivalence vs the trainer, report schema, stage-resume with stub
  manifests, eval_release wiring pins.
- `docs/evals-runbook.md`: GPU-box bringup (uv extra install), checkpoint
  staging from hub branches/GCS, milestone cadence (log-spaced + best + LAWA
  + final), expected ranges (Seamless-class tr/hi ballparks; BLEU < 5
  caveat), reporting checklist (judge ids, NORM_VERSION, subset digest,
  decoding params), API-key handling via env.
- Sync: v0.3 model card `results:` TODO + release-plan §3 point at this

## Implementation addendum (2026-07-15, same day)

Everything above landed; deviations/findings:

1. **`.pt` gold-text keys are `src_text`/`tgt_text`** (not
   `source_text`/`target_text` as the dataset card writes) — verified live on
   host 0; the corpus also carries `src/tgt_lang`, `src/tgt_duration_s`,
   `pair_id`, `voice`, all embedded into frozen subsets.
2. **`v03-val-500` frozen on host 0** from the staged val split (62,036
   rows): 250/direction, gold text on all rows,
   sha256 `91c7e2753e86a6a1…` (self-verified + test-pinned).
3. **FLEURS leakage finding:** the overlap audit (normalized-text match vs
   `tr-hi-parallel-text`, 103,342-entry exclusion set) found **200/200
   drawn `fleurs_real` rows' texts inside the training corpus** — the corpus'
   FLORES slice IS the FLEURS sentence inventory. `v03-fleurs-200`
   (100/direction, real human recordings, sha256 `cd556805a9662662…`) is
   therefore framed as **real-speech ACOUSTIC domain shift only**, with the
   audit recorded in its header (`--overlap_policy record`).
4. **Dependency split:** `unbabel-comet` (numpy<2) and `sonar-space`
   (fairseq2 torch pins) are unresolvable against the training lock → they
   live in a standalone eval venv (runbook §"Semantic venv");
   everything else went into the `[eval]` extra. `eval_release.py`
   lazy-imports the model stack so `--stages semantic,report` runs in that
   venv.
5. **Free-running AR text** added to `eval_checkpoint.generate_autoregressive`
   (`free_text=`/`return_text=`, defaults preserve old behavior) — the honest
   AR text-translation mode feeding `eval/gold_chrfpp_ar_*`.
6. Tests: 30 new/updated in `tests/test_evaluation.py` (+ pins moved in
   `test_hardening_prelaunch.py`); torch-free CI-safe.
